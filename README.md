# 📊 TikTok Analytics Dashboard

Dashboard interactivo desarrollado en Power BI para analizar el rendimiento de contenido en TikTok.

## 🚀 Objetivo
Analizar métricas clave como:
- Visualizaciones
- Engagement
- Seguidores
- Rendimiento por días

## 📈 Funcionalidades
- Evolución temporal de visualizaciones
- Distribución de engagement (likes, comentarios, compartidos)
- Top 5 días con mayor rendimiento
- Segmentación por mes

## 🛠️ Tecnologías
- Power BI
- DAX
- CSV como fuente de datos
